# Журнал оценки: неделя 0

Этот файл обновляется после проверки каждой практической работы. Он хранит не только баллы, но и историю исправлений.

## Правила оценивания

- Первая попытка оценивается как самостоятельная исходная работа.
- Ошибки не удаляются из истории после исправления: рядом записывается результат повторной проверки.
- Итоговый балл может быть повышен после самостоятельного исправления.
- Подсказка не штрафуется, если после неё решение понято и воспроизведено.
- Скопированный фрагмент, который ученик не может объяснить, считается невыполненным.
