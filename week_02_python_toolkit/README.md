## Критические ошибки

- основной сценарий не запускается;
- функция принимает или возвращает данные вопреки заявленному контракту;
- изменяемое значение по умолчанию создаёт общее состояние между вызовами;
- ошибка скрывается пустым `except` или безусловным возвратом фиктивных данных;
- декоратор теряет возвращаемое значение или не поддерживает аргументы задания;
- генератор загружает весь поток в память вопреки условию;
- файл остаётся открытым из-за неправильной работы с ресурсом;
- путь зависит от случайной текущей директории;
- вызывается `pickle.load()` для недоверенных данных;
- деньги рассчитываются через бинарный `float`, когда задание требует `Decimal`;
- импорт создаёт неожиданный интерактивный запуск программы;
- ученик не может объяснить основную конструкцию.
