## Критические ошибки недели

- public endpoint раскрывает secret/internal field;
- anonymous/non-staff получает staff write;
- public catalog становится writable;
- balance/inventory/history получает generic writable CRUD;
- DELETE физически удаляет используемую reference/history row;
- HTTP-layer дублирует/обходит atomic service;
- serializer сохраняет непроверенные `initial_data`;
- invalid request оставляет partial database state;
- pagination нестабильна и теряет/дублирует rows;
- N+1 растёт линейно между N=2 и N=20;
- unexpected exception раскрывает traceback, SQL, filesystem path или secret;
- schema заявляет contract, которого нет в runtime;
- project не запускается на основном сценарии;
- tests направлены не в isolated test database.
