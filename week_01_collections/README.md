# Неделя 1: коллекции Python

Статус модуля: **подготовлен заранее и заблокирован**.

Приступать к заданиям можно только после полного завершения недели 0 и появления допуска в `week_00_basics/ASSESSMENT.md`. До этого материалы можно просматривать, но не нужно писать решения или менять статус этого модуля.

## Цель

Научиться уверенно хранить, изменять, группировать, сравнивать и сортировать наборы данных с помощью:

- списков;
- кортежей;
- словарей;
- множеств;
- вложенных коллекций;
- comprehensions;
- встроенных функций обработки коллекций.

Главный результат — самостоятельный консольный анализатор продаж и складских остатков автосалонов.

## Предварительные требования

До начала недели 1 ученик должен:

- получить зачёт за каждый день недели 0;
- получить минимум 8/10 за итоговый проект недели 0;
- пройти финальную проверку недели 0;
- уметь писать функции, условия и циклы;
- уметь читать простые исключения;
- получить явный допуск в `week_00_basics/ASSESSMENT.md`.

Если одно из условий не выполнено, активным остаётся модуль недели 0.

## Порядок прохождения

1. Прочитать назначенный раздел `THEORY.md`.
2. До запуска предсказать результат контрольных примеров.
3. Выполнить задания дня в соответствующем `.py`-файле.
4. Проверить обязательные сценарии.
5. Заполнить самооценку в конце файла.
6. Попросить проверить конкретный день.
7. Самостоятельно исправить обязательные замечания.
8. Получить итоговый статус в `ASSESSMENT.md`.

Каждый учебный «день» может занимать больше одного календарного дня.

## Что считается освоенным навыком

Ученик должен не только получить правильный вывод, но и уметь:

- объяснить выбор структуры данных;
- предсказать, изменится ли исходная коллекция;
- назвать возможные ошибки операции;
- проверить пустую коллекцию и дубликаты;
- оценить порядок временной сложности основной операции;
- переписать похожее решение на новых данных без копирования.

## Ограничения недели

До первой проверки не использовать для решения основных заданий:

- `pandas`, NumPy и другие внешние библиотеки;
- базу данных;
- классы;
- `collections.Counter`, `defaultdict` и готовые группировщики;
- чтение CSV/JSON;
- сложные однострочные выражения, которые ученик не может объяснить;
- сортировку пузырьком вместо встроенной сортировки, если задача не просит реализовать алгоритм;
- преобразование в `set`, если по условию нужно сохранить исходный порядок дубликатов.

После ручной реализации отдельных задач можно сравнить решение с `Counter` или `defaultdict`, но они не заменяют понимание словаря.

## Критические ошибки недели 1

- основной файл не запускается;
- входная коллекция неожиданно изменяется вопреки условию;
- код теряет данные или дубликаты, которые нужно сохранить;
- словарь обращается к отсутствующему ключу без предусмотренного поведения;
- программа падает на обязательном пустом наборе;
- ученик не может объяснить выбранную структуру;
- решение задачи целиком заменено неизвестной готовой библиотекой;
- итоговый проект выдаёт неверные суммы продаж или остатки.

## Критерий завершения недели

- каждый день получил итоговую оценку не ниже 7/10;
- итоговый анализатор получил не ниже 8/10;
- исправлены все критические ошибки;
- ученик уверенно отвечает минимум на 18 из 24 контрольных вопросов;
- ученик может объяснить различия `list`, `tuple`, `dict`, `set`;
- ученик может выбрать коллекцию для новой небольшой задачи;

- ученик знает сложность основных операций на практическом уровне.
