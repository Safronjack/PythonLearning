# Теория недели 1: коллекции Python

Не приступай к практическим файлам до полного зачёта недели 0. Конспект можно просматривать заранее.

Каждый пример нужно сначала прочитать, предсказать результат и только потом запустить самостоятельно.

## 1. Что такое коллекция

Коллекция хранит несколько значений внутри одного объекта.

Без коллекции:

```python
first_model = "Camry"
second_model = "X5"
third_model = "A6"
```

Со списком:

```python
models = ["Camry", "X5", "A6"]
```

Основные слова недели:

- **коллекция** — объект, содержащий несколько элементов;
- **элемент** — отдельное значение внутри коллекции;
- **итерация** — один шаг обхода коллекции;
- **итерируемый объект** — объект, элементы которого можно последовательно обходить;
- **последовательность** — упорядоченная коллекция, поддерживающая позиционный доступ;
- **индекс** — номер позиции элемента;
- **ключ** — объект, по которому словарь находит значение;
- **изменяемость** — возможность изменить содержимое существующего объекта;
- **хешируемость** — возможность получить устойчивый хеш и использовать объект как ключ словаря или элемент множества.

Четыре основные структуры:

| Структура | Порядок | Повторы | Изменяется | Основной способ доступа |
|---|---|---|---|---|
| `list` | Да | Да | Да | Индекс/обход |
| `tuple` | Да | Да | Нет | Индекс/обход |
| `dict` | Порядок вставки | Ключи — нет, значения — да | Да | Ключ |
| `set` | Не использовать как упорядоченный | Нет | Да | Проверка наличия/обход |

Не существует «лучшей коллекции вообще». Выбор зависит от операции, которую программа выполняет чаще всего.

## 2. Списки: создание и чтение

### Создание

```python
models = ["Camry", "X5", "A6"]
empty_models = []
another_empty_list = list()
```

Список технически может хранить разные типы:

```python
mixed = ["Camry", 31_000, True, None]
```

Но для прикладного кода обычно проще, когда элементы имеют один понятный смысл. Для одной машины с несколькими полями позже удобнее словарь или класс.

### Индексы

Индексация начинается с нуля:

```python
models = ["Camry", "X5", "A6"]

first = models[0]
second = models[1]
last = models[-1]
```

Отрицательные индексы идут с конца:

- `-1` — последний элемент;
- `-2` — предпоследний.

Обращение за пределы списка вызывает `IndexError`:

```python
models[10]
```

Перед позиционным доступом программа должна иметь основание считать, что элемент существует.

```python
if models:
    print(models[0])
```

### Длина

```python
count = len(models)
```

Последний допустимый положительный индекс равен `len(models) - 1`, если список не пуст.

### Проверка наличия

```python
if "Camry" in models:
    print("Модель найдена")

if "Civic" not in models:
    print("Модель отсутствует")
```

Список проверяет элементы последовательно, поэтому поиск по значению занимает `O(n)` в общем случае.

## 3. Срезы последовательностей

Срез создаёт выбранную часть последовательности:

```python
models = ["Camry", "X5", "A6", "Civic", "Corolla"]

first_two = models[0:2]
from_second = models[1:]
up_to_third = models[:3]
every_second = models[::2]
reversed_models = models[::-1]
```

Форма:

```text
collection[start:stop:step]
```

- `start` включается;
- `stop` не включается;
- `step` задаёт шаг;
- отсутствующая граница означает начало или конец в направлении шага.

Срез обычно не вызывает `IndexError`, если границы выходят за диапазон: Python ограничивает их фактической длиной.

```python
print(models[:100])
```

Шаг не может быть нулём.

```python
# ValueError
models[::0]
```

Срез списка создаёт новый внешний список, но вложенные изменяемые элементы остаются общими. Это shallow copy и будет подробно разобрано позже.

## 4. Изменение списка

### Замена элемента

```python
models = ["Camry", "X5", "A6"]
models[1] = "Civic"
```

Можно заменить срез:

```python
models[1:3] = ["Civic", "Corolla"]
```

Размер списка при присваивании срезу может измениться, если количество новых элементов отличается.

### `append()`

Добавляет **один объект** в конец:

```python
models.append("Civic")
```

Если передать список, он станет одним вложенным элементом:

```python
models.append(["Corolla", "Accord"])
```

### `extend()`

Добавляет элементы итерируемого объекта по одному:

```python
models.extend(["Corolla", "Accord"])
```

Строка тоже итерируема. Поэтому это почти наверняка ошибка:

```python
models.extend("BMW")
```

Будут добавлены отдельные символы.

### `insert()`

```python
models.insert(1, "Civic")
```

Вставляет перед указанным индексом. Вставка в начало или середину требует сдвига элементов и обычно стоит `O(n)`.

### `remove()`

```python
models.remove("Camry")
```

Удаляет первое равное значение. Если значение не найдено, возникает `ValueError`.

```python
if "Camry" in models:
    models.remove("Camry")
```

### `pop()`

Удаляет и возвращает элемент:

```python
last_model = models.pop()
first_model = models.pop(0)
```

Пустой список или неверный индекс вызывает `IndexError`. `pop()` с конца обычно быстрый, а `pop(0)` сдвигает остальные элементы и стоит `O(n)`.

### `del`

```python
del models[0]
del models[1:3]
```

`del` удаляет по позиции и не возвращает удалённое значение.

### `clear()`

```python
models.clear()
```

Очищает существующий список. Это отличается от привязки имени к новому пустому списку, если на старый список указывают другие переменные.

### Методы, изменяющие список, возвращают `None`

```python
result = models.append("Camry")
print(result)  # None
```

Частая ошибка:

```python
models = models.append("Camry")
```

После этого `models` станет `None`. Методы `append`, `extend`, `insert`, `remove`, `sort`, `reverse`, `clear` изменяют список на месте и не возвращают новый список.

## 5. Обход и обработка списков

### Обход элементов

```python
for model in models:
    print(model)
```

Если нужен и индекс:

```python
for index, model in enumerate(models):
    print(index, model)
```

Не используй `range(len(models))`, когда индекс не нужен.

### Накопление

```python
prices = [31_000, 47_000, 42_000]
total = 0

for price in prices:
    total += price
```

### Поиск

```python
found_model = None

for model in models:
    if model == "Camry":
        found_model = model
        break
```

Если достаточно ответа `True`/`False`, оператор `in` обычно понятнее.

### Фильтрация

```python
affordable_prices = []

for price in prices:
    if price <= 40_000:
        affordable_prices.append(price)
```

Исходный список сохраняется, а результат создаётся отдельно.

### Не изменять размер во время обхода

Проблемный код:

```python
for price in prices:
    if price <= 0:
        prices.remove(price)
```

После удаления элементы сдвигаются, и цикл может пропустить часть данных. Безопаснее:

- создать новый отфильтрованный список;
- обходить копию, если изменение исходного списка действительно требуется;
- сначала собрать позиции/значения для удаления.

### `index()` и `count()`

```python
position = models.index("Camry")
occurrences = models.count("Camry")
```

`index()` возвращает позицию первого совпадения и вызывает `ValueError`, если совпадения нет. Обе операции обходят список и имеют `O(n)`.

## 6. Сортировка и разворот списка

### `sorted()`

Создаёт новый список из итерируемого объекта:

```python
prices = [47_000, 31_000, 42_000]
sorted_prices = sorted(prices)
```

Исходный список не изменяется.

### `.sort()`

```python
prices.sort()
```

Изменяет существующий список и возвращает `None`.

### Убывание

```python
descending = sorted(prices, reverse=True)
```

### `key`

```python
models = ["camry", "X5", "a6"]
alphabetical = sorted(models, key=str.lower)
```

`key` вычисляет значение для сравнения, но в результат попадают исходные элементы.

Для словарей:

```python
cars = [
    {"model": "Camry", "price": 31_000},
    {"model": "X5", "price": 47_000},
]

by_price = sorted(cars, key=lambda car: car["price"])
```

`lambda` здесь — короткая безымянная функция. Если выражение становится сложным, лучше написать обычную именованную функцию.

### Несколько критериев

```python
ranking = sorted(
    cars,
    key=lambda car: (-car["sales"], -car["revenue"], car["model"]),
)
```

Кортежи сравниваются слева направо. Отрицательное число превращает числовой критерий в порядок по убыванию, пока общий `reverse=True` не подходит из-за разных направлений.

### Стабильность

Сортировка Python стабильна: элементы с одинаковым ключом сохраняют относительный порядок. Это позволяет выполнять сортировку в несколько проходов, начиная со второстепенного критерия.

### Несравнимые типы

В Python нельзя осмысленно отсортировать смесь вроде:

```python
[10, "Camry", None]
```

Нужно привести данные к единому смыслу или предоставить подходящий `key`.

## 7. Кортежи

Кортеж — упорядоченная неизменяемая последовательность.

```python
car = ("Toyota", "Camry", 2024)
empty = ()
single = ("Camry",)
```

Запятая, а не скобки, создаёт одноэлементный кортеж:

```python
not_a_tuple = ("Camry")
one_item_tuple = ("Camry",)
```

### Чтение

```python
brand = car[0]
last_value = car[-1]
part = car[:2]
```

Поддерживаются индексы, срезы, `len`, `in`, `count`, `index` и обход.

### Неизменяемость

```python
# TypeError
car[0] = "BMW"
```

Нельзя заменить, добавить или удалить отдельный элемент существующего кортежа.

Но неизменяемость поверхностная:

```python
data = ("Camry", [31_000, 30_000])
data[1].append(29_000)
```

Сам кортеж продолжает ссылаться на тот же список, но содержимое вложенного списка изменилось.

Кортеж с вложенным списком не будет хешируемым и не сможет стать ключом словаря.

### Упаковка и распаковка

```python
car = "Toyota", "Camry", 2024
brand, model, year = car
```

Количество имён должно соответствовать количеству элементов, если не используется `*`:

```python
first, *middle, last = [10, 20, 30, 40]
```

`middle` всегда становится списком.

Можно игнорировать значение по соглашению:

```python
model, _, price = ("Camry", 2024, 31_000)
```

`_` технически остаётся обычным именем, но сообщает, что значение не используется.

### Возврат нескольких значений

```python
def calculate_statistics(prices):
    return min(prices), max(prices)


minimum, maximum = calculate_statistics([31_000, 47_000])
```

Функция возвращает один кортеж, который затем распаковывается.

### Когда выбирать кортеж

- набор имеет фиксированный смысл и не должен изменяться;
- значение используется как составной ключ;
- функция возвращает несколько связанных результатов;
- нужно явно выразить неизменяемость структуры.

Кортеж не является заменой модели данных с большим количеством неочевидных позиций. Позже для такой задачи будут изучены `dataclass` и классы.

## 8. Словари

Словарь сопоставляет уникальные ключи значениям:

```python
car = {
    "brand": "Toyota",
    "model": "Camry",
    "price": 31_000,
}
```

### Создание

```python
empty = {}
also_empty = dict()
car = dict(brand="Toyota", model="Camry")
```

В форме с именованными аргументами ключи становятся строками и должны быть допустимыми именами. Литерал словаря универсальнее.

### Ключи

Ключи:

- уникальны;
- должны быть хешируемыми;
- чаще всего являются строками, числами, кортежами неизменяемых значений или enum-значениями.

Если ключ повторён при создании, последнее значение заменяет предыдущее:

```python
car = {"price": 31_000, "price": 30_000}
```

Это не способ хранить несколько цен. Для нескольких значений нужна другая структура.

### Доступ через `[]`

```python
price = car["price"]
```

Отсутствующий ключ вызывает `KeyError`. Это полезно, когда отсутствие ключа означает ошибку данных.

### `get()`

```python
discount = car.get("discount")
discount = car.get("discount", 0)
```

`get()` не изменяет словарь. Без второго аргумента он возвращает `None`.

Важно различать:

- ключ отсутствует;
- ключ существует со значением `None`.

Если различие важно, используй проверку `key in dictionary`.

### Добавление и изменение

```python
car["stock"] = 5
car["price"] = 30_000
```

Один синтаксис добавляет отсутствующий ключ и заменяет существующее значение.

### `setdefault()`

```python
sales_by_model = {}
sales_by_model.setdefault("Camry", 0)
sales_by_model["Camry"] += 1
```

Если ключ существует, значение не заменяется. Если отсутствует — создаётся со значением по умолчанию. Для простого числового подсчёта часто понятнее `get()`.

`setdefault()` особенно полезен для подготовки вложенной изменяемой коллекции, но сначала нужно понимать ручную проверку ключа.

### `update()`

```python
car.update({"price": 29_000, "stock": 4})
```

Существующие ключи заменяются, новые добавляются.

Оператор объединения словарей создаёт новый словарь в поддерживаемых версиях Python:

```python
updated_car = car | {"price": 29_000}
```

При совпадении ключа побеждает правый словарь.

### Удаление

```python
removed_price = car.pop("price")
del car["stock"]
car.clear()
```

`pop()` возвращает удалённое значение. Для отсутствующего ключа можно предоставить значение по умолчанию:

```python
removed = car.pop("unknown", None)
```

### Обход

```python
for key in car:
    print(key)

for key in car.keys():
    print(key)

for value in car.values():
    print(value)

for key, value in car.items():
    print(key, value)
```

Обычный обход словаря идёт по ключам.

Проверка `in` также относится к ключам:

```python
"price" in car
```

Для значения нужна явная проверка:

```python
31_000 in car.values()
```

### Порядок

Современный Python сохраняет порядок вставки ключей в словарь. Это не означает сортировку. Если нужен отсортированный вывод, сортируй ключи или пары явно.

### Изменение размера во время обхода

Нельзя безопасно добавлять или удалять ключи при прямом обходе того же словаря. Можно обновлять значение существующего ключа, но структурные изменения лучше выполнять после сбора нужных ключей или при обходе копии ключей.

### Подсчёт

```python
models = ["Camry", "X5", "Camry"]
counts = {}

for model in models:
    counts[model] = counts.get(model, 0) + 1
```

Эта схема важна для будущих агрегатов базы данных и статистики.

### Группировка

```python
buyers_by_dealership = {}

for sale in sales:
    dealership = sale["dealership"]
    buyer = sale["buyer"]

    if dealership not in buyers_by_dealership:
        buyers_by_dealership[dealership] = []

    buyers_by_dealership[dealership].append(buyer)
```

Позже список можно заменить множеством, если нужны уникальные покупатели.

### Вложенные словари

```python
inventory = {
    "Tbilisi Center": {
        "Camry": 3,
        "X5": 1,
    },
    "Batumi Auto": {
        "Camry": 2,
    },
}
```

Доступ:

```python
camry_stock = inventory["Tbilisi Center"]["Camry"]
```

Каждый уровень может вызвать `KeyError`. Выбор между строгим `[]` и безопасным `get()` зависит от того, является ли отсутствие данных ошибкой или нормальным случаем.

## 9. Множества

Множество хранит уникальные хешируемые элементы:

```python
models = {"Camry", "X5", "A6"}
```

### Пустое множество

```python
empty_set = set()
empty_dict = {}
```

`{}` создаёт словарь, а не множество.

### Уникальность

```python
models = {"Camry", "Camry", "X5"}
```

В множестве останется один `"Camry"`.

Не используй множество, если количество повторений имеет смысл или нужен исходный порядок.

### Порядок и индекс

Не полагайся на порядок вывода множества. У множества нет позиционного доступа:

```python
# TypeError
models[0]
```

Если нужен отсортированный вывод:

```python
for model in sorted(models):
    print(model)
```

### Добавление

```python
models.add("Civic")
models.update(["Corolla", "Accord"])
```

`add()` добавляет один элемент, `update()` — элементы итерируемого объекта.

### Удаление

```python
models.remove("Camry")
models.discard("Unknown")
removed = models.pop()
models.clear()
```

- `remove()` вызывает `KeyError`, если элемента нет;
- `discard()` ничего не делает при отсутствии;
- `pop()` удаляет произвольный элемент, а не «последний»;
- `clear()` очищает множество.

### Операции множеств

```python
dealer = {"Camry", "X5", "A6"}
supplier = {"Camry", "Civic", "A6"}

all_models = dealer | supplier
common_models = dealer & supplier
only_dealer = dealer - supplier
only_one_side = dealer ^ supplier
```

Методы-аналоги:

```python
dealer.union(supplier)
dealer.intersection(supplier)
dealer.difference(supplier)
dealer.symmetric_difference(supplier)
```

Операторы требуют set-подобные операнды, а методы могут принимать произвольные итерируемые объекты в некоторых операциях. Для начинающего лучше явно преобразовать данные и сохранять единообразие.

### Отношения множеств

```python
preferred = {"Camry", "A6"}
available = {"Camry", "A6", "X5"}

preferred <= available       # подмножество
available >= preferred       # надмножество
preferred < available        # строгое подмножество
preferred.isdisjoint({"X5"})
```

### `frozenset`

`frozenset` — неизменяемое множество:

```python
allowed_roles = frozenset({"buyer", "admin"})
```

Оно может быть ключом словаря или элементом другого множества, если все элементы хешируемы. На практике недели 1 достаточно понимать назначение.

## 10. Comprehensions

Comprehension создаёт новую коллекцию из итерируемого объекта.

### Список

Обычный цикл:

```python
affordable = []

for price in prices:
    if price <= 40_000:
        affordable.append(price)
```

List comprehension:

```python
affordable = [price for price in prices if price <= 40_000]
```

Порядок чтения:

1. Что попадёт в новый список: `price`.
2. Откуда берутся значения: `for price in prices`.
3. Какой фильтр: `if price <= 40_000`.

### Преобразование

```python
discounted = [price * 0.9 for price in prices]
```

### Фильтр и условное выражение — разные вещи

Фильтр удаляет элементы:

```python
positive = [value for value in values if value > 0]
```

Условное выражение сохраняет каждый элемент, но выбирает значение:

```python
labels = ["positive" if value > 0 else "not positive" for value in values]
```

### Словарь

```python
price_by_model = {
    car["model"]: car["price"]
    for car in cars
}
```

Если вычисленный ключ повторяется, более позднее значение заменяет раннее.

### Множество

```python
unique_buyers = {sale["buyer"] for sale in sales}
```

### Когда не использовать

Не помещай в comprehension:

- несколько уровней сложных условий;
- изменение внешнего состояния;
- `print()` ради побочного эффекта;
- длинную бизнес-логику;
- выражение, которое трудно объяснить.

Сначала научись писать понятный цикл, затем сокращай только очевидную обработку.

Вложенные comprehensions рассматриваются обзорно. В неделе 1 они не обязательны.

## 11. Полезные встроенные функции

### `enumerate()`

```python
for position, model in enumerate(models, start=1):
    print(position, model)
```

Используй, когда одновременно нужны элемент и номер. `start` меняет отображаемый счётчик, но не индексы самого списка.

### `zip()`

```python
models = ["Camry", "X5"]
prices = [31_000, 47_000]

for model, price in zip(models, prices):
    print(model, price)
```

Обычный `zip()` останавливается на самой короткой коллекции. Несовпадение длин может незаметно потерять данные.

В актуальном Python можно потребовать равные длины:

```python
zip(models, prices, strict=True)
```

Тогда несовпадение приводит к `ValueError`.

### `len()`

Возвращает количество элементов верхнего уровня:

```python
len([[1, 2], [3, 4]])  # 2
```

### `sum()`

```python
total = sum(prices)
```

Не используй `sum()` для объединения строк или списков. Для текста есть `str.join()`, а списки обычно наращиваются осознанно или объединяются подходящей операцией.

### `min()` и `max()`

```python
lowest = min(prices)
highest = max(prices)
```

Пустая коллекция без значения `default` вызывает `ValueError`.

```python
lowest = min(prices, default=None)
```

Для объектов можно предоставить `key`:

```python
cheapest_car = min(cars, key=lambda car: car["price"])
```

Возвращается исходный объект, а не само значение ключа сортировки.

### `any()`

```python
has_empty_stock = any(stock == 0 for stock in stocks)
```

Возвращает `True`, если хотя бы один элемент истинный. Для пустого итерируемого объекта возвращает `False`.

### `all()`

```python
all_in_stock = all(stock > 0 for stock in stocks)
```

Возвращает `True`, если все элементы истинны. Для пустого итерируемого объекта возвращает `True`: не найдено ни одного элемента, нарушающего условие. В бизнес-задаче иногда нужна дополнительная проверка, что данные вообще есть.

### `reversed()`

```python
for model in reversed(models):
    print(model)
```

Возвращает объект для обратного обхода и не изменяет исходную последовательность.

## 12. Изменяемость, alias и копирование

### Alias

```python
original = ["Camry", "X5"]
alias = original
alias.append("A6")
```

`original` и `alias` указывают на один список. Присваивание не копирует объект.

Можно проверить идентичность:

```python
print(original is alias)
```

`==` сравнивает значения, `is` — идентичность объектов. В обычных расчётах значения сравниваются через `==`; `is` принято использовать для `None` и редких задач идентичности.

### Shallow copy

```python
copy_one = original.copy()
copy_two = original[:]
copy_three = list(original)
```

Для плоского списка эти копии позволяют независимо добавлять и заменять элементы.

### Вложенная изменяемость

```python
inventory = [["Camry", 3], ["X5", 2]]
inventory_copy = inventory.copy()
inventory_copy[0][1] = 0
```

Внешние списки различны, но вложенные списки общие. Поэтому изменение видно через обе переменные.

### Deep copy

```python
from copy import deepcopy

independent = deepcopy(inventory)
```

`deepcopy` рекурсивно копирует вложенные объекты, но:

- может быть дорогим;
- не всегда соответствует смыслу модели;
- иногда правильнее создать новую структуру явно;
- не должен использоваться автоматически при любом сомнении.

### Копирование словаря и множества

```python
car_copy = car.copy()
models_copy = models.copy()
```

Эти методы также создают shallow copy.

### Параметры функции

При передаче списка функция получает ссылку на тот же объект:

```python
def add_model(models, model):
    models.append(model)
```

Функция изменяет список вызывающего кода. Это может быть намеренно, но должно быть ясно из контракта и имени. Если изменение не требуется, создай новый результат.

## 13. Хешируемость и хеш-таблица

### Практическое определение

Хешируемый объект:

- имеет хеш, который не меняется во время его жизни;
- поддерживает корректное сравнение;
- может быть ключом словаря или элементом множества.

Обычно хешируемы:

- `int`, `float`, `str`, `bool`, `None`;
- кортеж, если все его элементы хешируемы;
- `frozenset`, если его элементы хешируемы.

Обычно не хешируемы:

- `list`;
- `dict`;
- `set`.

Изменяемый объект нельзя безопасно использовать как ключ: после изменения его было бы трудно найти в таблице по прежнему хешу.

### Упрощённая модель словаря

1. Python вычисляет хеш ключа.
2. По хешу выбирает место для поиска.
3. Если кандидаты есть, сравнивает ключи на равенство.
4. Возвращает соответствующее значение.

### Коллизия

Коллизия возникает, когда разные ключи приводят к одному участку хеш-таблицы или одному хешу. Корректная таблица разрешает коллизию и продолжает различать ключи через дополнительные проверки.

Коллизия не означает, что одно значение автоматически перезапишет другое. Перезапись происходит, когда ключи считаются равными.

### Почему `dict` и `set` быстрые

Благодаря хеш-таблице поиск ключа/элемента в среднем близок к `O(1)`. Это средний случай, а не абсолютная гарантия.

## 14. Временная сложность

`n` — количество элементов.

| Операция | Средняя сложность | Причина |
|---|---:|---|
| `list[index]` | `O(1)` | позиционный доступ |
| `tuple[index]` | `O(1)` | позиционный доступ |
| `value in list` | `O(n)` | последовательный поиск |
| `list.append(value)` | амортизированно `O(1)` | обычно есть резерв памяти |
| `list.pop()` с конца | `O(1)` | нет сдвига остальных |
| вставка/удаление в начале списка | `O(n)` | элементы сдвигаются |
| копирование списка | `O(n)` | создаются ссылки на элементы |
| срез списка длины `k` | `O(k)` | создаётся новый список |
| сортировка | `O(n log n)` | алгоритм сравнивает элементы |
| `dict[key]` | в среднем `O(1)` | хеш-таблица |
| запись/удаление ключа словаря | в среднем `O(1)` | хеш-таблица |
| `value in set` | в среднем `O(1)` | хеш-таблица |
| добавление/удаление в set | в среднем `O(1)` | хеш-таблица |
| `min`, `max`, `sum` | `O(n)` | нужен обход элементов |

Амортизированное `O(1)` означает: отдельное расширение списка иногда дороже из-за выделения памяти, но средняя стоимость серии `append()` остаётся постоянной на операцию.

Не оптимизируй маленькую учебную программу заранее. Сложность нужна, чтобы избегать явно неудачной структуры при росте данных.

Пример:

- один поиск в коротком списке — нормально;
- тысячи повторных проверок наличия в большом списке — возможно, нужен `set`;
- требуется сохранить порядок и дубликаты — один `set` не подходит.

## 15. Как выбирать структуру

Задай вопросы:

1. Нужен ли порядок?
2. Нужны ли повторы?
3. Нужен ли доступ по позиции?
4. Нужен ли доступ по смысловому ключу?
5. Нужно ли быстро проверять наличие?
6. Должна ли структура изменяться?
7. Важно ли количество повторений?

Примеры:

| Задача | Подходящая структура | Почему |
|---|---|---|
| История продаж | `list` | важны порядок и все записи |
| Фиксированные координаты | `tuple` | фиксированный набор |
| Цена по модели | `dict` | доступ по названию модели |
| Уникальные покупатели | `set` | уникальность и быстрый membership |
| Остатки по автосалону и модели | вложенный `dict` | два смысловых ключа |
| Составной ключ «автосалон + модель» | `tuple` внутри `dict` | кортеж хешируем |
| Рейтинг моделей | `list` | нужен сортируемый порядок |

Иногда данные проходят через несколько структур: история остаётся списком, а для быстрого поиска дополнительно строится множество или словарь.

## 16. Типичные ошибки недели 1

- ожидать, что индексы начинаются с 1;
- забывать, что `stop` среза не включается;
- обращаться к первому элементу пустого списка;
- путать `append()` и `extend()`;
- присваивать результат `append()` или `sort()` обратно переменной;
- удалять элементы при обходе того же списка;
- считать `pop(0)` быстрой очередью;
- забывать запятую в одноэлементном кортеже;
- считать любой кортеж хешируемым;
- использовать список как ключ словаря;
- считать `get()` операцией добавления ключа;
- забывать, что `in` у словаря проверяет ключи;
- полагаться на порядок множества;
- использовать `{}` как пустое множество;
- применять set для удаления дубликатов, когда нужно сохранить порядок;
- путать `remove()` и `discard()` множества;
- не замечать, что `zip()` обрезал данные;
- делать сложный нечитаемый comprehension;
- ожидать полной независимости shallow copy;
- применять `all()` к пустым данным без осознания результата;
- возвращать результат `list.sort()`;
- сортировать значения несовместимых типов.
