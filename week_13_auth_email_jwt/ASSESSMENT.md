## Критические ошибки недели

- raw password присваивается, хранится или логируется;
- API не вызывает configured password validators;
- raw action/JWT token или signing key попадает в database/log/schema/Git;
- action token принимается endpoint другого purpose;
- expired/used/revoked token меняет state;
- concurrent consumption выполняет transition дважды;
- email/login меняется до подтверждения нового адреса;
- identity conflict оставляет partial update;
- security link строится из untrusted request Host;
- inactive/unverified user получает login/refresh/protected access вопреки contract;
- JWT identity claim основан на mutable email/login;
- refresh и access взаимозаменяемы;
- rotation/logout/revocation не соответствует заявленному contract;
- password reset/resend раскрывает account existence через public body/status;
- password change/reset не отзывает sessions по принятой policy;
- throttle tests отсутствуют либо side effect происходит после 429;
- throttle представлен как точная anti-brute-force/DoS гарантия;
- tests отправляют реальные письма или используют shared/production DB/cache;
- OpenAPI содержит working credential или расходится с runtime;
- основной lifecycle не запускается.
