## Правила проверки

Наставник до запуска проверяет Redis/PostgreSQL targets, prefix и отсутствие опасных cleanup commands. Первая оценка и ошибки сохраняются. Для каждого сценария фиксируются exact command/node ID, Redis/API/DB result, duration/failure class и cleanup evidence.
